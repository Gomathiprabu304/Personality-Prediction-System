# 🧠 Personality Prediction System Through CV Analysis

## 📌 Project Overview
This project is built as part of the HexSoftwares Internship Program.
It uses Natural Language Processing (NLP) and Machine Learning to analyze
a candidate's CV or Resume and predict their personality traits.
The system maps CV text to the Big Five (OCEAN) personality model and
provides improvement tips and career suggestions based on the results.

---

## 🎯 What This Project Does
- Reads a CV file (PDF or Word format)
- Extracts and analyzes the text using NLP
- Predicts scores for 5 personality traits
- Shows improvement tips for weak areas
- Highlights strengths to use in career
- Suggests best career paths based on personality

---

## 🧬 The 5 Personality Traits (OCEAN Model)

| Trait | Simple Meaning |
|-------|---------------|
| 🎨 Openness | How creative and curious you are |
| 📋 Conscientiousness | How organised and hardworking you are |
| 🗣️ Extraversion | How social and outgoing you are |
| 🤝 Agreeableness | How kind and cooperative you are |
| 🧘 Emotional Stability | How calm you are under pressure |
